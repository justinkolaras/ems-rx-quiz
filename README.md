# RxRapid — EMS Med Quiz

Prescription drug practice for EMS students, built for people starting from zero.

- **Learning path:** 8 levels / 30 short lessons (read → quiz). Pass each lesson (75%), then the level test (80%) to unlock the next level.
- **Rapid-fire review** of everything you've learned, with spaced repetition.
- **Advanced practice** across all 240 drugs with medic-level questions:

- **Drug → Class / Category** (lisinopril → ACE inhibitor → antihypertensive)
- **Class → Drug**, **Brand ↔ Generic**, **Suffixes** (-pril, -olol, -statin…)
- **Med list → Patient history** (metformin + atorvastatin + lisinopril → diabetes, high cholesterol, HTN)
- **EMS field scenarios** (PDE5 + nitro, beta-blocker OD, anticoagulated head injury…)

Spaced repetition brings missed cards back quickly. Progress saves automatically in the browser, with backup download/restore in Settings.

Study aid only — always follow local protocols and medical direction.
